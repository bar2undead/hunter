# 云端冒险：双人联网版

Node.js + WebSocket 实时双人合作闯关，基于原单机版关卡改造。

## 本地运行

安装 Node.js 18+，在本目录执行：

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。同一 Wi-Fi 下的其他设备可以用你的电脑局域网 IP 加 `:3000` 访问；互联网联机需要部署到公开服务器。

## 免费部署（Render）

1. 在 GitHub 创建仓库，将此目录里的 `package.json`、`server.js`、`public/` 上传到仓库根目录。
2. 在 Render.com 创建 **New > Web Service**，连接该 GitHub 仓库。
3. Runtime 选 Node；Build Command 填 `npm install`；Start Command 填 `npm start`；选择可用的 Free 方案。
4. 部署成功后，复制 Render 提供的 `https://...onrender.com` 网址给朋友。
5. 玩家 A 点击「创建房间」并把六位数字告诉玩家 B；玩家 B 输入房间号点击「加入房间」。两人都到达终点后进入下一关。

注意：免费服务通常会休眠，首次打开可能需要等待。服务重启后房间数据会消失。房间只保存在服务器内存中，不支持掉线后保留原玩家位置。无需数据库或额外 API 密钥。

## 游戏操作

电脑：←/→ 或 A/D 移动，空格/↑/W 跳跃；手机：触控按钮。

## 联网规则

服务器负责人物物理、碰撞、金币、敌人、分数、关卡和生命状态；客户端只发送按键并绘图。每个房间最多两人，使用六位房间号。断线时房间进入等待状态；如果有人离开，新的玩家可用原房间号加入。仅用于小规模朋友间试玩，未提供登录、反作弊和持久化存档。
